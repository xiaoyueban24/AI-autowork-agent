# 参赛作品文案合集（竞品调研）

> 来源：https://aitalking.zjipc.cn/star/competition（需学校统一认证登录）
> 用途：学习其他参赛作品的标题写法、开头钩子、正文结构、配图风格，为「智备教案」投稿提供参考
> 采集日期：2026-09-03（首次创建，待登录后补充）

## 使用方法

1. 打开《竞品观察室.html》（工作台「窗口2」），在「实时浏览」标签页内登录学校统一认证
2. 逐个点开作品详情页，把值得学习的内容按下面模板记录
3. 截图（Win + Shift + S）保存到 `竞品分析/screenshots/`，并在 `screenshots-manifest.json` 里登记

## 作品记录模板

```markdown
### 【作品 N】标题原文
- **形式**：图文经验帖 / 短视频 / 实操文档
- **一句话简介**：（作品描述原文）
- **开头钩子**：（正文第一段怎么抓注意力的）
- **结构**：（分了几节，各节写什么）
- **亮点**：（值得抄的点：标题句式/配图/提示词分享/数据对比…）
- **可借鉴到智备教案**：（具体怎么用）
- **截图**：screenshots/xxx.png
```

## 平台情报（已确认）

| 项目 | 内容 |
|------|------|
| 作品数据接口 | `/api/applications/Competition/all`（需登录，Bearer/Cookie） |
| 作品详情接口 | `/api/applications/Competition/{id}` |
| 作品构成字段 | 标题 · 描述 · 标签 · 正文 · 封面 · 附件 · 点赞状态(isMyLike) |
| 登录方式 | 学校 CAS 统一认证（学号/工号） |
| 评分规则 | 大众点赞 50% + 专家评审 50%（实用性/创新性/完整性/推广性） |
| 投稿形式 | 图文经验帖 / 短视频 ≤5分钟 / 实操文档 |
