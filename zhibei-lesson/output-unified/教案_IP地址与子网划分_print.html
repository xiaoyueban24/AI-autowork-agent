一、教学目标

1. 知识目标：掌握 IP地址的概念与分类、子网掩码的作用、子网划分的方法、CIDR 无类别编址 的基本概念、原理与方法。
2. 能力目标：能运用 IP地址的概念与分类 相关知识分析与解决实际问题。
3. 素养目标：培养严谨求实的科学态度与职业素养。

二、教学重点与难点

重点：IP地址的概念与分类 的概念与核心方法
难点：子网掩码的作用 的理解与应用

三、教学准备

多媒体课件、板书、课堂练习材料、网络学习平台

四、教学过程

环节时间教师活动学生活动设计意图
一、导入新课5以生活/岗位实例设疑引入，展示学习目标。观察情境，思考并回答提问。创设情境、激活前备知识。
二、新课讲授40知识点1「IP地址的概念与分类」：讲解概念 → 演示案例 → 归纳要点，结合课件与板书逐步展开。；知识点2「子网掩码的作用」：讲解概念 → 演示案例 → 归纳要点，结合课件与板书逐步展开。；知识点3「子网划分的方法」：讲解概念 → 演示案例 → 归纳要点，结合课件与板书逐步展开。；知识点4「CIDR 无类别编址」：讲解概念 → 演示案例 → 归纳要点，结合课件与板书逐步展开。听讲记笔记，参与问答与课堂练习。由浅入深突破重难点。
三、巩固练习25布置分层练习与小组任务，巡回指导纠错。独立或协作完成任务，互评互纠。即时检测，学以致用。
四、课堂小结10梳理知识框架，强调重难点与易错点。回顾总结，提出疑问。形成结构化记忆。
五、作业布置10布置课后作业与拓展任务。记录作业与要求。巩固课堂所学，延伸课外。
