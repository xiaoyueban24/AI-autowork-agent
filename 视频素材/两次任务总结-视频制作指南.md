## 一、任务 1：旅游足迹地图（travel 项目）

**用户诉求**：把 Excel 里的旅游记录变成可视化足迹地图 + 时间线。

**AI 实际做了什么（全部自动完成）**：
1. 读取用户 Excel 旅游数据，生成 `travel-timeline.html`（dshell 皮肤：时间线/足迹统计/标记地图三标签页），挂载到工作台窗口1
2. 用户要求装 GitHub 开源项目 StarMap（Aisland-SJL/StarMap，CesiumJS 3D 地球）→ AI 自动 clone、npm ci、启动 dev server（处理了公司网络 TLS 证书问题、端口占用冲突）
3. 帮用户申请/配置两个免费地图 API：天地图 Key（32字符）+ Cesium ion Token（303字符 JWT），写入 `.env.local`，重启服务生效
4. 用户上传含名字+地址的照片文件夹 → AI 按文件夹名（地点）把照片挂到地图对应位置
5. 写「一键启动StarMap.bat」，git 建仓 + 推送到 GitHub

**技术要点**：Windows 批处理 GBK+CRLF 编码坑、npm.ps1 执行策略绕行（用 npm.cmd）、Vite --strictPort 端口冲突处理、天地图/Cesium 双源影像切换。

## 二、任务 2：智备教案 AI 大赛作品（AI_competition 项目 · 当前）

**用户诉求**（演进过程）：
1. 窗口1：读全部历史会话，完成「电信杯」AI应用大赛任务 → 生成投稿作战板 + 9 张投稿图
2. 窗口2：爬取竞品网站（被 CAS 登录挡住 → 降级为 iframe 内嵌实时浏览方案）
3. 窗口3：展示所有真实产出（6 个课件 iframe + 图集 + Word 预览）
4. 窗口4：学习网上「一键生成PPT」方案（Gamma/Kimi PPT 模式：大纲先行→逐页填充→主题渲染），自研实现：任意主题 → HTML课件+PPTX+PDF 三件套
5. 最终融合：**一体化生成台**——填一次课上课内容，一次出齐 Word教案 + 教案A4PDF + 课件PPTX/HTML/PDF 六件套；支持自定义 AI 接口地址（OpenAI 兼容）；AI 四轮迭代（联网检索→初稿→自我评审→优化定稿），PPTX 自动加转场/入场动画/演讲者备注
6. git 建仓 + 推送 GitHub（xiaoyueban24/AI-autowork-agent），处理 schannel SSL 问题
7. 文件夹整理 + 一键启动.bat + **保留程序生成过程的视频素材**（本任务）

**核心技术自研**（都在 `zhibei-lesson/`）：

- `pipeline.js` 四轮迭代教案生成（检索→初稿→评审→定稿，含 JSON 修复重试）
- `unified.js` 一体化流水线：教案 docx（gen-docx）+ A4 打印 HTML→Edge 无头打印 PDF + dsh-slides 课件三件套 + PowerPoint COM 动画打磨（polish-pptx）
- `server.js`：异步任务（/api/unified 提交 → taskId → /status 轮询实时阶段），CORS 跨域支持
- Edge 无头 `--print-to-pdf`（Word COM 挂死问题的绕行方案）

## 五、给视频模型的制作建议

**故事线（推荐 60-90 秒竖版或 3 分钟横版）**：
1. **钩子**（0-5s）：字幕「我向 AI 说了一句话」→ 用户输入框特写
2. **想法阶段**（5-15s）：截图 01/02 —— 填课程信息、配置自己的 API 接口
3. **生成过程**（15-30s）：录屏 01 剪辑加速 —— 实时阶段条 + AI 四轮（检索→初稿→评审→定稿字幕逐个弹出）
4. **结果揭晓**（30-50s）：截图 04 六件套逐个高亮 → 08/09 课件翻页 → 10 教案打印版
5. **升华**（50-70s）：截图 07 首页 + GitHub 仓库 → 字幕「从一句话到完整作品，全程 AI 自动完成」
6. **片尾**：作品名「智备教案」+ 仓库地址 + 作者

**剪辑提示**：录屏 01 的关键时间点 —— 0s 打开页面 / ~8s 填写表单 / ~18s 点击生成 / ~30s 完成 / ~40s 预览课件 / ~60s AI课件翻页。
配音可用免费 TTS（剪映自带朗读）；BGM 选轻快电子乐；字幕关键词：AI、一键生成、四轮迭代、六件套。
